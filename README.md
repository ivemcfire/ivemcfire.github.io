# ivemcfire.github.io

Source for my engineering blog → **https://ivemcfire.github.io**

Static HTML on GitHub Pages, no build step. Long-form write-ups on running Kubernetes on bare metal:

- **Frigate NVR on k3s** — nine cameras, object detection, Cloudflare Tunnel access, nightly backups
- **K3s phone cluster** — a Kubernetes cluster built from OnePlus phones on postmarketOS
- **The sidecar pattern** — a Fluent Bit sidecar for logging + metrics on a FastAPI app
- **Local AI on k3s** — Ollama and GPU-passthrough experiments

Posts live in `posts/`, images in `images/`; a push to `main` deploys via GitHub Pages.
